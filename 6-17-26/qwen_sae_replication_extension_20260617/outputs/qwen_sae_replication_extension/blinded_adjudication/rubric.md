# Blinded Output Adjudication Rubric

Score each row without using the hidden key. The prompt text is visible because task compliance and semantic drift cannot be judged without the input.

Columns to add during adjudication:

- `refusal`: none / partial / full
- `introspective_register`: none / weak / strong
- `semantic_drift`: none / mild / major
- `task_compliance`: complete / partial / failed
- `surface_form_commentary`: none / mentions characters / focuses on characters
- `degeneration`: none / repetition / truncation / incoherence / empty
- `notes`: short free-text rationale

These labels are not central evidence until adjudication is complete and the key is joined after scoring.
